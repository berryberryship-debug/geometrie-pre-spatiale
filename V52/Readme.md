# MCC — Moteur de Cohérence Contextuelle (Version 52)

**Version 52** — Refonte propre, publique et testée.

Ce package contient un petit moteur de simulation d'états dynamiques (charge, régulation, contexte, stress) protégé par **chaînage cryptographique SHA-256** et **signatures Ed25519**.

---

## 📦 Installation

Le projet nécessite Python 3.10+ et la bibliothèque `cryptography`. 

```bash
pip install -r requirements.txt
